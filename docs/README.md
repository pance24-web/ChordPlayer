# Dokumentasi ChordPlayer

Folder ini berisi dokumentasi teknis dan operasional untuk proyek ChordPlayer.

## Isi dokumentasi

| File | Tujuan |
|---|---|
| [`Changelog.md`](./Changelog.md) | Riwayat perubahan dan catatan implementasi proyek. |
| [`dark-mode-guide.md`](./dark-mode-guide.md) | Panduan penerapan dan pemeliharaan mode gelap. |
| [`schema.sql`](./schema.sql) | Skema database untuk tabel lagu dan data terkait. |
| [`../todo.md`](../todo.md) | Daftar pekerjaan utama dan prioritas proyek. File ini adalah satu-satunya sumber TODO. |
| [`../CP handoff/START_HERE.md`](../CP%20handoff/START_HERE.md) | Titik awal untuk membaca dokumen handoff desain dan implementasi. |

## Konvensi struktur

Dokumentasi umum dan panduan teknis ditempatkan di folder `docs/`. Daftar pekerjaan proyek disimpan di root sebagai `todo.md` agar mudah ditemukan. Dokumen handoff dipertahankan di folder `CP handoff/` karena menjadi paket referensi khusus untuk kesinambungan desain dan implementasi.

Jangan membuat salinan `todo.md` di subfolder lain. Jika daftar pekerjaan perlu diperbarui, ubah [`todo.md`](../todo.md) di root repository.
